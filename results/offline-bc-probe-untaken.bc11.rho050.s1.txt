Both labellings are real routes through the same maze from the same cell. The gap between
them is what is specific to the route this model will actually walk; without it, an AUC over
an untrained baseline shows only that the network represents the layout.

The trained probe must beat the untrained one at the same depth. Beating
only the observation shows the network mixes cells, which it does before
any training at all.
